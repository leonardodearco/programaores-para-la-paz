Resultados de la prueba de ejecución del servidor:

1. ¿Qué ocurre cuando ejecutas node server.js?
Al ejecutar este comando, el entorno de Node.js compila el archivo de JavaScript y levanta un proceso en segundo plano que inicializa nuestro servidor web Express, dejándolo a la escucha en la red local.

2. ¿Qué mensaje aparece en la terminal?
En la pantalla de la terminal se imprime el mensaje programado en el callback de escucha: "Servidor ejecutándose en puerto 3000". El cursor se queda bloqueado, lo que indica que el proceso sigue activo.

3. ¿Qué sucede cuando visitas la ruta /estado?
Cuando ingreso desde el navegador a http://localhost:3000/estado, el cliente realiza una petición HTTP de tipo GET. El servidor intercepta la ruta '/estado' y responde de inmediato enviando un objeto estructurado en formato JSON con la siguiente información:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
